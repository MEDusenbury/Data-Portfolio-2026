# Michael Dusenbury Data Portfolio

Data Analytics Portfolio

## Featured Projects

### [Health vs. Wealth: Does Money Buy a Longer, Happier Life?](Health%20vs%20Wealth%20Portfolio%202026/README.md)
Investigation into relationships between national wealth, life expectancy, and suicide rates across 187 countries using WHO, World Bank, and Pew Research data. Three hypotheses tested; findings include Preston Curve confirmation and a religiosity-suicide signal.

### [Internet Traffic Analysis: Mapping Global Adoption 2005–2023](Internet%20Traffic%20Portfolio%202026%20v1.0/README.md)
Investigation into global internet user growth patterns, cyclical adoption peaks, and recession-resistance of internet adoption using World Bank API data.
